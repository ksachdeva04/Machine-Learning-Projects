# Customer Churn Prediction

## Project Overview
This project uses machine learning to predict whether a customer is likely to leave a service.

## Objectives
- Explore and understand customer data.
- Clean and preprocess data for machine learning.
- Train and compare classification models.
- Evaluate model performance.

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure
- `cust_churn.ipynb` — data preprocessing, model training, and evaluation.

## Results
Model performance and conclusions are documented in the notebook. Results should be verified before drawing final conclusions.
