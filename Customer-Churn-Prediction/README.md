# Customer Churn Prediction

## Project Overview
This project uses machine learning classification models to predict whether a customer is likely to leave a service.

## Objectives
- Explore and understand customer data.
- Clean and preprocess data for machine learning.
- Train and compare classification models.
- Evaluate model performance.

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure
- `cust_churn.ipynb` — notebook containing data exploration, preprocessing, model training, and evaluation.

## Model Evaluation
The notebook evaluates models using accuracy, classification reports, and confusion matrices. The results should be verified for potential data leakage before drawing final conclusions.
